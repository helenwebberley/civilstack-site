# civilstack.ai

The website for CivilStack (https://civilstack.ai), Doug Foster's AI tools for construction.

Plain static HTML, served by GitHub Pages. Edit `index.html`, `privacy.html` or `style.css`, commit and push, and the site updates within a minute or two.

- `index.html`: home page
- `privacy.html`: privacy policy (the App Store links here)
- `img/`: app icon and App Store screenshots
- `CNAME`: tells GitHub Pages the domain is civilstack.ai
